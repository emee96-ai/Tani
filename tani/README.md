# تاني | Tani

Sudanese multi-vendor marketplace MVP for Android.

## Included
- Kotlin + XML + Material 3
- Supabase Auth + PostgreSQL REST
- Customer browsing, cart and orders
- Seller onboarding and basic seller dashboard
- Transactional order RPC with stock protection
- Arabic RTL-friendly interface

## Build
Open the `tani` folder in Android Studio, let Gradle sync, then Build > Build APK(s).

Supabase project is configured in `app/src/main/java/com/tani/app/data/Supabase.kt` using a publishable key only.
