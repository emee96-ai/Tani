# سياسة الاحتفاظ بالبيانات والحذف — مسودة

- تجمع تاني الحد الأدنى اللازم للتشغيل والثقة والدعم والتحليلات.
- بيانات العرض الشخصية تُعطل وتُجهّل عند حذف الحساب.
- متجر ومنتجات التاجر تُعطل عند حذف حساب المالك.
- الطلبات، سجلات الدفع/التسوية، النزاعات وسجلات التدقيق قد تُحتفظ بها للمدة اللازمة قانونياً وتشغيلياً.
- وثائق هوية التاجر تعامل كبيانات عالية الحساسية وتبقى في مساحة تخزين خاصة وصلاحيات محدودة.
- يجب تحديد مدد احتفاظ رقمية نهائية بعد المراجعة القانونية المحلية ومتطلبات الضرائب/المحاسبة/التسوية.
