# المرحلة السادسة — Room Cache وOffline State

## الهدف
نقل كاش السوق من SharedPreferences إلى Room مع version/expiry واضح، وإظهار حالة الاتصال للمستخدمة بدل انتظار مهلة الشبكة أو عرض خطأ عام.

## التنفيذ
- Room cache عام لبيانات السوق مع مفاتيح منفصلة للرئيسية، المنتجات، المتاجر، والتوصيات.
- ترحيل تلقائي لمحتوى SharedPreferences القديم عند أول قراءة ناجحة ثم حذف المفتاح القديم.
- رفض أي cache version قديم حتى في وضع offline، مع السماح بقراءة البيانات المنتهية فقط عند طلب fallback صريح.
- كشف الاتصال عبر ConnectivityManager وNetworkCapabilities.
- الرئيسية والمنتجات والمتاجر تعرض بيانات محفوظة فوراً عند انقطاع الشبكة مع رسالة واضحة.
- توصيات الحساب تبقى معزولة لكل مستخدم كما في المرحلة الخامسة.

## معايير النجاح
