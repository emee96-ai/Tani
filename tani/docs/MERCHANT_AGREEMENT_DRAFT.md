# تاني — اتفاقية التاجر (مسودة تشغيلية)

> تحتاج مراجعة قانونية محلية قبل الإطلاق التجاري.

بتقديم طلب تاجر، يوافق التاجر على:
- تقديم هوية وبيانات متجر صحيحة وقابلة للتحقق.
- عدم البيع قبل الاعتماد، وعدم التحايل على حالة التحقق.
- إبقاء السعر، المخزون، الوصف والصور ومعلومات التوصيل دقيقة ومحدثة.
- قبول/رفض الطلبات ضمن وقت معقول وعدم تأخير العميل دون تحديث.
- احترام حالات الطلب المعتمدة وعدم إعلان التسليم قبل التسليم الفعلي.
- تحمل مسؤولية التوصيل ورسومه عندما يكون التوصيل من المتجر، ما لم تعتمد المنصة نموذجاً آخر لاحقاً.
- عدم عرض المنتجات المحظورة أو غير القانونية أو المقلدة أو التي تتطلب ترخيصاً غير متوفر.
- الاستجابة للشكاوى وقرارات الدعم وفق سياسة المنصة.
- عدم التلاعب بالتقييمات أو الطلبات أو الإحالات أو مؤشرات الأداء.

يمكن لتاني طلب تعديلات، رفض الطلب، تعليق التاجر أو إلغاء الظهور عند المخالفات. يتم توثيق الإجراءات الإدارية في Audit Logs.

الاشتراكات، الرسوم، الإعلانات والظهور المميز لا تُفرض إلا إذا كانت القواعد والأسعار مفعلة ومعلنة. أي محتوى مدفوع يظهر بوسم «ممول».
