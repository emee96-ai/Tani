# سياسة المنتجات المحظورة — مسودة

يحظر عرض أي منتج غير قانوني في منطقة التشغيل، أو يتطلب ترخيصاً لا يملكه البائع، أو منتج مقلد/مسروق، أو محتوى ينتهك حقوق الآخرين أو سلامة المستخدمين. يحق للإدارة إخفاء المنتج أو تعطيله والتحقيق في التاجر.

القائمة التفصيلية للمواد المنظمة والممنوعة يجب اعتمادها قانونياً قبل الإطلاق التجاري وتحديثها عند تغير الأنظمة المحلية.
